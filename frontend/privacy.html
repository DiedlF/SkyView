Privacy policy

How Skyview handles data

Skyview is designed as a lightweight weather visualization service. This policy describes the data the current application can process.

Launch note: Complete the operator details in the Impressum and review this policy before making the service public or paid.

Controller

The responsible operator is listed in the Impressum. The operator details must be completed before public launch.

Server logs

When you use Skyview, the server may process request metadata such as time, path, response status, duration, IP address, user agent, and request id. These logs are used for operations, abuse prevention, debugging, and security.

Usage statistics

Skyview records aggregate page-load statistics. Estimated unique visitors are calculated from a salted hash of IP address, user agent, and accepted language. Raw IP addresses are not stored in the usage statistics file, but they may still appear in server or hosting logs.

Local storage

The frontend stores a language preference and a random client id in your browser local storage. The client id is used to associate marker preferences with the same browser.

Location and markers

If you use browser location features, your browser asks for permission before sharing your location. Skyview uses that location to display or set map markers. If marker editing is enabled, marker name, note, latitude, longitude, client id, and creation time may be stored on the server.

Feedback

If you send feedback, Skyview stores your message, feedback type, timestamp, and application context such as model, run, selected time, map center, zoom, and selected overlay. Feedback requests are rate-limited by IP address.

Third-party requests

The current frontend loads Leaflet and uPlot from unpkg.com and map tiles from Esri ArcGIS services. Your browser may send request metadata, including your IP address, to those providers. For a paid public launch, self-hosting frontend libraries should be considered.

Retention

Operational logs, feedback, marker data, and aggregate usage statistics are kept only as long as needed for operations, support, abuse prevention, and product improvement, unless legal obligations require a different retention period.

Your rights

Depending on applicable law, you may have rights to access, correction, deletion, restriction, objection, portability, and complaint to a supervisory authority. Contact details are provided in the Impressum.
